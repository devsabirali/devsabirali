# GitHub Profile Setup — Private Contributions & Snake

## 1. Private repo contributions not showing

### Step A — Turn on in GitHub (required)

1. Go to **github.com → Settings → Profile**
2. Under **Contributions & activity**, check:
   - **Include private contributions on my profile**
3. Save

After this, your **GitHub profile page** shows green squares for private work (repo names stay hidden).

### Step B — README widgets (stats / streak)

Third-party badges (streak, stats cards) only see what GitHub exposes publicly. The README now uses `count_private=true` on streak and stats URLs.

**Limits you should know:**

| Widget | Private commits counted? | Private repo names shown? |
|--------|--------------------------|---------------------------|
| GitHub profile graph | Yes (if setting ON) | Never |
| Streak / stats badges | Partial — only if setting ON | Never |
| Language cards | Usually **no** — public repos only | Never |
| Snake animation | Yes (if setting ON) | Never |

Language breakdown cards **cannot** include private repos — that is a GitHub API limitation, not a README bug.

## 2. Snake animation not showing

The snake is **not automatic**. It must be generated by a GitHub Action in your profile repo.

### Requirements

- Repo name must be exactly: **`devsabirali`** (same as your username)
- File: **`devsabirali/devsabirali`**

### Setup steps

1. Open your profile repo on GitHub: `https://github.com/devsabirali/devsabirali`

2. Create folder and file:
   - Path: **`.github/workflows/snake.yml`**
   - Copy contents from `github-profile-snake.yml` in this folder

3. Enable Actions (if prompted):
   - **Settings → Actions → General → Allow all actions**

4. Run the workflow manually:
   - **Actions** tab → **Generate Snake** → **Run workflow** → **Run workflow**

5. Wait 1–3 minutes. Check that branch **`output`** exists:
   - `https://github.com/devsabirali/devsabirali/tree/output`

6. Verify the file exists:
   - `https://raw.githubusercontent.com/devsabirali/devsabirali/output/github-contribution-grid-snake-dark.svg`

7. Update `README.md` with the latest content from `github-profile-README.md`

### If snake still broken

| Problem | Fix |
|---------|-----|
| **File in wrong place** | Must be `.github/workflows/snake.yml` — **NOT** `github-profile-snake.yml` in repo root |
| Actions tab empty | Add workflow to `.github/workflows/` folder |
| Workflow failed | Open failed run → read error log |
| No `output` branch | Re-run workflow; check `contents: write` permission |
| Broken image icon | `output` branch not created yet — complete steps above |
| Very few green dots | Normal if you have few commits on GitHub |

The snake eats dots from your **GitHub contribution graph** — not from local Git commits unless they were pushed to GitHub.
